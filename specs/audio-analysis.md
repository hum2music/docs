# Audio Analysis Engine Spec

対応：PRD §6。`packages/audio-analysis`。

## 入力・前処理

- 対応フォーマット：WAV/PCM、44.1kHz / 48kHz
- ステレオ入力は内部でモノラル化（L/Rの単純平均。提案値・要検証：位相干渉がある素材では平均化が歪む可能性があり、将来的にRMSベースのチャンネル選択も検討）
- 推奨録音時間：5〜60秒、主に単旋律・背景音の少ない録音を前提とする（PRD §6.1）

## 基本周波数推定（YIN）

- フレームサイズ・ホップサイズ：提案値として frame=2048 samples / hop=256 samples（44.1kHz時、約46ms窓・5.8msステップ）。実データでベンチマークし調整する。
- YINの差分関数・CMNDF（累積平均正規化差分関数）からの閾値（提案値 0.10〜0.15）で候補ピッチ周期を選択
- 放物線補間でサブフレーム精度のピッチ周期を求め、周波数へ変換
- 信頼度 = `1 - CMNDFの最小値`（0-1に正規化）。`PitchFrame.confidence`として保持
- 周波数→MIDIノート番号変換：

  ```
  m = 69 + 12 * log2(f / 440)
  ```

  四捨五入前の実数値を保持し、微小な音程変化（ビブラート等）を失わない（PRD §6.2）

## 発音区間（ノート境界）の検出

- 音量（RMSエンベロープ）変化・ピッチ変化・無音区間の組み合わせで境界を推定する
- 新規オンセット判定の提案条件：
  - ピッチが直近の移動中央値から一定量（提案値：50セント以上）乖離
  - RMSエンベロープに十分な立ち上がり（アタック）がある
  - 直前フレームが無音/無声から有声へ遷移した
- 同一音高が連続する場合も、アタックの変化（RMSの再上昇）から再分割を試みる（PRD §6.3）
- 鼻歌は子音が明確でないことが多いため、各ノート境界候補に信頼度を付与し、後段（リズム量子化・編曲）が低信頼区間を区別できるようにする

## ノイズ・異常値処理

- 短時間（提案値：1〜2フレーム未満）の孤立したピッチ異常値は前後のフレームから補間/除外する
- ピッチ軌跡の平滑化：移動平均または軽量なカルマン風フィルタ（過度な平滑化はビブラートを消すため、ウィンドウ幅は要調整）
- 一定時間以上（提案値：150ms以上）の無音を休符として扱う
- 有声/無声判定：YINの周期性スコアとRMSのしきい値を併用
- 音程補正（平均律への丸め）と、意図的な音程変化（ビブラート・グライド）の除去は別処理とし、どちらも元のピッチ軌跡を破壊しない（PRD §6.4）

## 出力

- 生ピッチ軌跡（`PitchFrame[]`）と量子化前ノート候補（`NoteCandidate[]`）を常に保持し、常にJSONへダンプ可能にする（[data-model.md](./data-model.md)参照）
